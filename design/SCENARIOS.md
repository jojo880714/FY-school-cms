# SCENARIOS.md — 18 個情境應對手冊

## 顧問端

### S1 · 新顧問首次進 CMS
- **觸發**：員工第一次從 Nexus 點進語校 CMS，尚無任何案件。
- **顧問動作**：瀏覽案件首頁。
- **系統行為**：案件列表為空 → 顯示引導卡「歡迎使用語校 CMS。點『+ 新建案件』開始為你的學生選校」。
- **預期結果**：顧問被引導點「＋ 新建案件」進入 wizard step 1。
- **⚠ 現況缺口**：引導卡（empty state）尚未實作於 `放洋 CMS.dc.html`，需補。

### S2 · 熟練顧問批次處理
- **觸發**：一個下午要連續 demo 3 個學生。
- **顧問動作**：在案件首頁快速切換不同學生案件。
- **系統行為**：案件卡可一鍵「查看 LP / 開報價」，狀態 chip 即時顯示進度。
- **預期結果**：顧問不需重新搜尋即可在案件間跳轉。

### S3 · 多任務並行
- **觸發**：5 個進行中案件同時推進。
- **顧問動作**：依「最後更新時間」與狀態排序判斷下一步。
- **系統行為**：案件卡顯示狀態 + LP/報價數量 + 最後更新時間。
- **預期結果**：顧問快速辨識哪個案件最該跟進。

### S4 · 跨工具 deep link
- **觸發**：從 Nexus 其他模組（CRM placeholder）帶 student 進 CMS。
- **顧問動作**：點 deep link。
- **系統行為**：CMS 以 Nexus 身份開啟，預填 student 基本資料進 wizard step 1。
- **預期結果**：免重複輸入學生資料。
- **⚠ TODO**：依賴 Nexus 傳參協定（見 OPEN_QUESTIONS T2/T3）。

### S5 · 模糊查詢
- **觸發**：顧問記不清學生姓名。
- **顧問動作**：用聯絡方式 / 諮詢日期搜尋。
- **系統行為**：搜尋框支援姓名 / 聯絡方式 / LP 標題比對。
- **預期結果**：以片段資訊找到案件。

### S6 · 誤刪 / 撤回
- **觸發**：誤刪案件或 LP。
- **顧問動作**：到 trash 入口還原。
- **系統行為**：案件 / LP 採軟刪除，保留可還原。
- **預期結果**：資料可救回。
- **⚠ 現況缺口**：trash 入口為設計概念，wireframe 未畫。

### S7 · 未儲存就關閉
- **觸發**：wizard 進行中直接關閉。
- **顧問動作**：下次再進入。
- **系統行為**：每 step 自動存草稿（localStorage + Supabase），再進入提示「未完成 · 草稿 Step N」。
- **預期結果**：續編不丟資料。

### S8 · 離線 / 慢網路
- **觸發**：demo 現場網路不穩。
- **顧問動作**：照常操作 wizard。
- **系統行為**：草稿先存 localStorage，網路恢復後同步 Supabase。
- **預期結果**：弱網不中斷工作流。

## 學生在現場（諮詢中）

### S9 · 學生改變主意
- **觸發**：demo 中學生說「英國太冷，看加拿大」。
- **顧問動作**：退到 wizard step 3 重選廠商 / 國家。
- **系統行為**：已 demo 過的學校與方案配置保留不丟。
- **預期結果**：重選不損失既有反應紀錄。

### S10 · 學生不確定
- **觸發**：5 校都被標「◌ 中立」。
- **顧問動作**：存草稿，安排 follow-up。
- **系統行為**：案件狀態維持「諮詢中」。
- **預期結果**：可延後決策。

### S11 · 學生帶家長
- **觸發**：家長現場追問費用細節。
- **顧問動作**：用諮詢模式即時試算回答；必要時開報價 wizard。
- **系統行為**：諮詢卡每校即時顯示課程 / 住宿 / 合計 / TWD。
- **預期結果**：當場給出可信數字。

## 報價環節

### S12 · 報價過期
- **觸發**：報價單超過有效期（預設 7 天）。
- **顧問動作**：重新開啟。
- **系統行為**：過期報價鎖原配置，提示是否重算。
- **預期結果**：避免用過期價誤報。
- **⚠ TODO**：有效期天數待確認（OPEN_QUESTIONS T5）。

### S13 · 報價多版本
- **觸發**：同案件出 2 次報價（漲價前後 / 不同方案）。
- **顧問動作**：在同案件下產生第二張報價。
- **系統行為**：`quotations` 表同案件多筆，案件卡顯示報價數。
- **預期結果**：版本並存可比對。

### S14 · 管理員看淨利
- **觸發**：管理員開啟報價單。
- **顧問動作**：無需 PIN。
- **系統行為**：Nexus role = manager 時，右側報價面板自動顯示實際成本 / 退傭 / 淨利。
- **預期結果**：權限分層，顧問版隱藏淨利。

## 資料管理

### S15 · 學校資料漲價
- **觸發**：廠商更新 SCHOOL_DATA。
- **顧問動作**：無。
- **系統行為**：已產 LP / 報價鎖價不連動；重產 LP 時用新資料。
- **預期結果**：歷史報價穩定。
- **⚠ TODO**：鎖價策略待確認（OPEN_QUESTIONS T6）。

### S16 · 新增廠商 / 校區
- **觸發**：新增 EP/ILSC… 校區或新廠商。
- **顧問動作**：照常選校。
- **系統行為**：現有 schema（schools/campuses/programs）支援，不影響使用。
- **預期結果**：擴充不破壞既有流程。

## 系統 / 內容

### S17 · 空狀態
- **觸發**：案件首頁無案件 / wizard step 3 過濾後無學校 / 報表本月無資料。
- **顧問動作**：瀏覽。
- **系統行為**：各處顯示對應 empty state 與引導。
- **預期結果**：空畫面不令人困惑。
- **⚠ 現況缺口**：empty state 尚未於 wireframe 完整實作。

### S18 · 錯誤狀態
- **觸發**：Supabase RLS 擋 / Edge Function 500 / 算費異常。
- **顧問動作**：重試或回報。
- **系統行為**：顯示錯誤提示 + 重試 / 回報入口。
- **預期結果**：錯誤可恢復、可回報。
- **⚠ 現況缺口**：error state 為設計概念，wireframe 未畫。
